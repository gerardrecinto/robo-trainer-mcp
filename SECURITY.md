# Security Policy

To report a vulnerability, email gerardrecinto@gmail.com. Please do not open a public issue for it.

Include what you found, how to reproduce it, and the version (`pip show robo-trainer-mcp`). I will reply as soon as I can. Only the latest release is supported.

What is in scope: the server stores your logs in a local SQLite file and calls one outside service, Open Food Facts, for food search. Reports about the audit log, the local database, input handling, or the container image are welcome.
