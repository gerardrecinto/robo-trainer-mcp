How it works

One local MCP server. Your data stays in a SQLite file on your machine.

1

Log in one place

Meals, sets, bodyweight, sleep and mood go into one local database, so Claude can read all of it together.

2

Ask across areas

Claude can pull volume, sleep, nutrition and mood in one answer, then reason about why a lift has stalled.

3

Stay local

No account. The only outside call is food search against Open Food Facts. Each tool call is audited to a local log.

Install

Python 3.12 or later. Not on PyPI yet, so install from source or use the image.

git clone https://github.com/gerardrecinto/robo-trainer-mcp
cd robo-trainer-mcp
pip install -e .
robo-trainer-mcp
{
  "mcpServers": {
    "trainer": {
      "command": "robo-trainer-mcp"
    }
  }
}

Put that in claude_desktop_config.json. A Docker image is at ghcr.io/gerardrecinto/robo-trainer-mcp.

What this does not do
  • It is a tool server, not a coach. Claude does the reasoning, and it can be wrong.
  • Nothing here is medical advice. The readiness and overreaching checks are simple heuristics.
  • Wilks and DOTS are standard formulas applied to the numbers you enter. They are only as good as those numbers.
