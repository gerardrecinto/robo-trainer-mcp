# Go-To-Market

## Positioning

Robo Trainer MCP gives Claude structured local access to training, nutrition, sleep, mood, and performance data so it can reason like a coach instead of answering from memory.

## Best First Customer

- Strength athletes who already track training but want better interpretation.
- Personal trainers who want AI-assisted client summaries.
- Powerlifters and strongman athletes managing fatigue and meet prep.

## Monetization Path

| Tier | Offer | Buyer |
|---|---|---|
| Open Source | Local MCP server and SQLite training memory. | Individual lifters and developers. |
| Pro | Mobile/web dashboard, sync, templates, advanced analytics. | Serious lifters. |
| Coach | Multi-client dashboards, summaries, assignments, check-ins. | Personal trainers. |
| API | Readiness, volume, and coaching endpoints. | Fitness apps. |

## Launch Hooks

1. "Your training log knows what happened. Your coach should know why."
2. "Claude can reason across sleep, food, mood, and training volume."
3. "Local-first AI coaching memory for strength athletes."
